01 Heat silicon, then measure how it movesLevel 1 stops here: The silicon has reached 2500 K. Motion and heat
First part

Level 1 · Task 1

What to do

Start with the supplied silicon crystal. Use the supplied Stillinger–Weber (SW) potential in LAMMPS. Make a 3 × 3 × 3 cell with 216 atoms. At zero pressure, heat it from 300 K to 2500 K over 1,000,000 steps of 1 femtosecond (fs) each. Save the final state and the temperature and density every 1,000 steps.

What to turn in

Turn in a JSON file that lists paths to the LAMMPS input, log, final restart state, and a table of 1,000 heating samples. Include the final energy and a file with the force on each of the 216 atoms.

How this part will be checked

The checker opens the files you turn in and checks the information inside them. All 3 checks must pass.

  1. Open the input and log. Check the starting cell, 216 silicon atoms, supplied SW potential, metal units, atom_style full, zero-pressure NPT setting, 1 fs step, heating rate of 2.2 K/ps, and final step 1,000,000. The run recorded in the log must match the input.
  2. Read all 1,000 rows in the heating table. Steps must run from 1,000 to 1,000,000 in order. Target temperature must follow the heating plan. Measured temperature and density must be valid positive numbers. Compare every row with the raw values in the LAMMPS log.
  3. Open the final state and force file. Check its 216 silicon atoms and velocities. Its density must be within 1% of the final log value, and the last 50 samples must average 2500 ± 250 K. Recalculate its energy and every atomic force with the supplied SW potential; compare with the saved values within 0.05 eV and 0.05 eV/Å per force component.

Level 2 · Task 1

What to do

Start with the supplied silicon crystal and complete the full Level 1 heating run, saving its final state and measurements. Then keep that same hot system running for 500 picoseconds (ps). Measure how far the atoms move every 1 ps, and use the last 250 measurements to calculate the liquid self-diffusion coefficient in m²/s.

What to turn in

Turn in a JSON file with the answer, a 500-row movement table, the raw LAMMPS measurements, and the input and log files.

Extra files for this plan

Also include the Level 1 final state, heating table, final energy, and force file so the heating stage can be checked.

How the full task will be checked

The checker opens all submitted files. The 3 Level 1 checks on the left and these 2 extra checks must all pass.

  1. Open the final state, production input, log, raw measurements, and 500-row table. Check that production starts at step 1,000,000 from the saved state and runs for 500 ps. Each table row must match the raw file and log at steps 1,001,000 through 1,500,000, 1,000 steps apart.
  2. Calculate the slope of the last 250 movement rows and divide it by 6, with the unit conversion to m²/s. The reported answer must be within 1% of this file-derived result; that result must be within 13.2% of 1.4440806734590084 × 10⁻⁸ m²/s.

Level 1 · Task 3

What to do

Place two silver atoms at 45 distances from 0.6 to 5.0 Å, in 0.1 Å steps. Use the supplied MACE-MP-0b model to calculate energy and force for each pair. Set aside the nine specified examples for testing. Save all examples in distance order and save the split.

What to turn in

Turn in a JSON file with paths to the 45-frame extxyz dataset and a split file. The split file lists training indices, test indices, and the SHA-256 digest of the supplied model.

How this part will be checked

The checker opens the files you turn in and checks the information inside them. All 3 checks must pass.

  1. Open the dataset. It must contain exactly 45 ordered frames of two silver atoms, at positions [0, 0, 0] and [distance, 0, 0] for distances 0.6–5.0 Å in 0.1 Å steps. There must be no periodic cell. Each frame must contain valid energy and forces.
  2. Open the split file. Test indices must be 4, 9, 14, 19, 24, 29, 34, 39, and 44. The other 36 indices must be the training set, with no repeats or overlap. Compare the saved model digest with the supplied model file.
  3. Recalculate energy and force for all 45 saved geometries with the supplied model, using its required float64, CUDA, and dispersion settings. Each saved value must match within relative tolerance 10⁻⁵ and absolute tolerance 10⁻³.

Level 2 · Task 3

What to do

Start with the supplied MACE-MP-0b model. Make and save all 45 silver-pair examples and the same train/test split required in Level 1. Train the model on the 36 training pairs and check it on the nine test pairs. Then use the trained model for a 5,000-step simulation of 108 silver atoms at 300 K.

What to turn in

Extra files for this plan

How the full task will be checked

The checker opens all submitted files. The 3 Level 1 checks on the left and these 3 extra checks must all pass.

  1. Open the trained checkpoint and evaluation file in a separate worker. Verify its SHA-256 digest, load its tensor-only state_dict with weights_only=True into the supplied model architecture, and check at least two valid training losses. Recalculate the nine test predictions and compare them with the saved predictions.
  2. From those nine test predictions, calculate energy and force error. Energy RMSE must be at most 0.1 eV per atom and force RMSE at most 0.2 eV/Å.
  3. Open the silver trajectory. Check 108 atoms, 5,000 Langevin steps with frames every 100 steps, and the final frame. Frames must contain positions, momenta, energy, forces, and the checkpoint digest. Recalculate three selected frames with the submitted model. The last ten frames must average 300 ± 30 K.

Level 2 · Task 6

What to do

Start with the original 64-atom aluminum cell. Complete the full Level 1 run at 300 K and save its final state. Then run that same system for 4,096 more steps without a thermostat, saving every step. Turn the saved atom velocities into a vibration spectrum (VDOS).

What to turn in

Turn in the vdos.csv file with frequency_thz and vdos columns.

Extra files for this plan

For this plan, submit a JSON file that links to vdos.csv, the Level 1 trajectory, final state, and settings, plus a second trajectory with the starting state and all 4,096 later frames.   3. Compare every saved VDOS row with the spectrum rebuilt from the trajectory: relative tolerance 1% and absolute tolerance 10⁻⁶ times the peak value. Its cosine similarity to a supplied reference spectrum must be at least 0.90.
